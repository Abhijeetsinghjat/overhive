# Security policy

Overhive can read source code, prompts, terminals and Git state on the machine it runs on, so we take
reports seriously.

**Report a vulnerability** privately through GitHub's "Report a vulnerability" (Security → Advisories) on
this repository. Please don't open a public issue. Include steps to reproduce and the affected version.
We aim to acknowledge reports within 7 days.

The threat model and mitigations are documented in [docs/SECURITY.md](docs/SECURITY.md).
